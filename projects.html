LexisAI: Adaptive Speech Therapy

A browser-native platform that turns any web browser into a personalized AI speech-language pathologist. It helps people with speech impediments, stuttering, and stroke-induced vocal loss through gamified, voice-interactive exercises. The core is an Adaptive Reinforcement Learning Engine that dynamically customizes recovery paths based on real-time vocal analysis using Web Audio APIs.

HTML CSS JavaScript GSAP Web Audio API RL
  • Browser-native speech therapy (no app install needed)
  • Real-time vocal frequency and phonemic analysis
  • Adaptive Reinforcement Learning difficulty engine
  • Gamified voice-interactive exercises
  • Localized for Bangla and English phonetics
  • Scalable globally by swapping language packages
