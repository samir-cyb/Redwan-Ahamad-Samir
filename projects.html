A domain-adapted AI assistant providing reliable academic guidance for Bangladeshi students. Python LLMs RAG Vector DB Firecrawl
  • RAG architecture with verified knowledge sources

  • Bilingual interaction with cited sources
  • Automated web crawling for university data
  • Vector database for semantic search
  • NCTB curriculum-aligned explanations
